# PI Coffee

A development harness that equips the original Pi Agent for software work.

## Language

**Pi Agent**: The upstream agent that reasons, calls tools and maintains its native conversation.

**Harness**: PI Coffee's instructions, tool selection and recovery behavior around Pi.

**Chat**: Conversation mode with the deliberately restricted tool and instruction contract.

**Work**: Software-development mode with project instructions and discoverable capabilities.

**Capability**: A named set of useful tools that the agent can discover and activate when needed.

**Evidence**: Retained source material that supports a result and can be recovered through its reference.

**Host**: The external application that owns execution and durable task data; it consumes the Pi package.
