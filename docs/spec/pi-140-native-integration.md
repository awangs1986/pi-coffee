narrow messageType before reading prompt. Host report-only runs must retain their
existing tool prohibition and run identity when custom messages trigger that hook.

defaultActive:false. Verify Coffee's request-time Chat filtering and upstream
activation across restore/model changes. Retain the previous Pi installed-package
matrix and add 1.4.0 with current upstream web/subagents.

inside cwd (for example launching from HOME). Other in-workspace session locations
remain rejected, and corrupt required journals remain blocking. Cover this through
ordinary native RPC input, not only path-helper tests.

provider, thinking and credentials. Do not run its convenience setup, which seeds
Grok defaults. OAuth login remains the user's native /login action; successful
package load is not evidence of xAI account entitlement. Its optional network and
media tools keep upstream opt-in behavior. Host explicitly selects package roots,
so its reviewed composition must include xAI independently of terminal settings.

packed-install/native activation checks, Host/Web native integration, MISHU native
