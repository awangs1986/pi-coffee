# PI Coffee issue tracker

PI Coffee tickets live in the internal Gitea repository [`awangs/pi-coffee`](http://testpc:3000/awangs/pi-coffee/issues). Issue titles, bodies, comments, status, and dependencies there are authoritative for this product line.

The Picode V5 repository is a separate frozen reference. Do not copy PI Coffee tickets into V5 or treat V5's issue list as a PI Coffee queue.

Use the numeric ticket prefix to order work when labels are unavailable. A ticket is complete only after its acceptance evidence is recorded as a comment and the issue is closed.
