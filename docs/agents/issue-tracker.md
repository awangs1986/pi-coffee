# PI Coffee issue tracker

PI Coffee tickets live in the internal Gitea repository [`awangs/pi-coffee`](http://testpc:3000/awangs/pi-coffee/issues). Issue titles, bodies, comments, status, and dependencies there are authoritative for this product line.

Read the versioned [`BACKLOG.md`](../../BACKLOG.md) and its [canonical backlog Issue #13](http://testpc:3000/awangs/pi-coffee/issues/13) for the complete discussion-derived decision register, delivery phases, open engineering questions, and explicit non-goals. Do not create a second private backlog on a workstation.

The Picode V5 repository is a separate frozen reference. Do not copy PI Coffee tickets into V5 or treat V5's issue list as a PI Coffee queue.

Use the numeric ticket prefix to order work when labels are unavailable. `D-*` and phase IDs in `BACKLOG.md` are stable cross-document identifiers; Gitea issue numbers remain the execution handles. A ticket is complete only after its acceptance evidence is recorded as a comment and the issue is closed.
